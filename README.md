# XXD Panel 347｜戏服小立像

上半保留原照，下半删去背景、地面和光影，让主体正面朝外、端端正正地站着，披一件单色斗篷或兜帽、或戴一顶尖帽，手边拄一根小棍或拎一件照片里的小东西，像绘本里一位准备远行的角色：几块透明水彩平涂，两颗小黑点眼睛，身后只有一整片暖白空底，脚下隔开一段空写一行淡淡的铅笔小注。

## 适用场景与解决的问题

适合想把一张宠物、家人或日常小物的照片变成绘本人物介绍页的时候：一只猫、一只狗、一位老人、一个孩子、一把茶壶、一盆仙人掌。也适合构图差、背景乱、主体小的照片——下半会删掉背景和地面、让主体正面站好、给它披上戏服、把照片里的一样东西变成手边的道具，把它救成一张认真又好笑的作品。照片里有好几个主体时，它们会并排站成一排、各穿各的戏服；照片是场景时，只取一个单体或片段来画。

关键是正面端正站立、一整块从肩头垂下的单色戏服、手边一件小道具、只用两颗小黑点做眼睛的脸、透明水彩干后留下的水痕和干笔扫出的毛、四周大片暖白留白，以及脚下隔开一段空的一行淡铅笔小注。避免完整场景复刻、背景或地面、侧身或跑跳、看不出角色的普通衣服、大眼睛的卡通脸、精细写实的毛发、浓重投影、黑线勾边和花哨配色。

## 使用窍门

- **先给一张清楚的照片：** 先选一张主体、动作和关系都容易辨认的图，再决定输出方式与比例。
- **一句话串起参数：** 直接说“上下对照 / 左右对照 / 纯设计 + 16:9 / 3:4 / 手机壁纸”，也可以补充电脑、平板或电子手表尺寸。
- **把必须保留的内容说清楚：** 指定人物、物件、动作、关系和文字；避免同时规定过多布局细节，让风格有空间完成设计。
- **文字有三种选择：** 让模型按图片智能生成、用 `--text exact --copy` 锁定逐字文案，或用 `--text none` 完全不要文字。
- **说明现实区与设计区：** 上下或左右对照时，注明哪一侧保留照片、哪一侧负责设计转译；纯设计和壁纸则说明整张画布都要重新设计。
- **先单张试，再批量做：** 先用一张图确认模式、比例、文字和语言，再把同一套参数用于目录批处理；每轮只改一个变量，结果更容易比较。

## 开始使用

从 GitHub 安装：

```bash
npx skills add https://github.com/nevertoday/xxd-panel-347 --skill xxd-panel-347
```

安装后重新启动 Agent 会话，然后调用 `$xxd-panel-347`。也可以按需追加 `--global --agent codex --yes` 做用户级安装。

常用调用示例：

```text
/xxd-panel-347 photo.jpg --mode top-bottom --size 3:4 --text prompt --locale zh-CN
/xxd-panel-347 photo.jpg --mode left-right --size 16:9 --text prompt --locale en-US
/xxd-panel-347 photo.jpg --mode design-only --size 9:16 --text none --prefs off
/xxd-panel-347 ./photos --mode design-only --size auto,3:4 --text prompt --locale ja-JP
```

完整运行契约见 [SKILL.md](SKILL.md)；运行适配器见 [英文](references/xxd-panel-347-prompt.en.md) 与 [中文](references/xxd-panel-347-prompt.zh-CN.md)。

## 快速判断：Panel 347 适合你吗？

既要保留源图身份，也要重新构图；既要材质特征，也要主动留白。可选准确文字、智能文案或无文字；支持单图、递归目录批量以及下方四种交付模式。

## 四种输出模式

- `top-bottom`：整张画布只有上下两个全宽区域，现实照片在上、设计在下，严格各占 50%。
- `left-right`：整张画布只有左右两个全高区域，现实照片在左、设计在右，严格各占 50%，不会旋转成上下结构。
- `design-only`：整张画布只呈现 Panel 347 的设计转译，照片只作为不可见参考。
- `wallpaper-pack`：按手机、iPad、桌面和手表分别生成完整设计壁纸，可选 `linked` 连贯套装或 `independent` 四张独立。

支持多选模式与比例（`1:1`、`3:4`、`4:3`、`4:5`、`5:4`、`2:3`、`3:2`、`9:16`、`16:9`、`21:9`、`5:7`、`7:5` 或准确像素），以及模型生成文字、准确文字和无文字。传入目录会递归扫描图片，每张源图独立处理，共用一次交付设置；最终 PNG 平铺放入一个新任务目录。
